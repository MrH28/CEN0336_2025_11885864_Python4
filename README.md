#Python 4: Listas e Loops

## Objetivo

Este notebook resolve os exercícios do conjunto **Python 4**, com foco nos fundamentos de Python:

- criação, alteração, cópia e ordenação de listas;
- uso de strings, `split()` e `join()`;
- estruturas de repetição `while` e `for`;
- uso de `range()` e compreensões de listas;
- cálculo de somas, fatoriais e identidades de sequências;
- manipulação de sequências de DNA.

## Conteúdo

A célula de código anterior contém soluções para:

1. Operações básicas com listas.
2. Separação e ordenação de nomes de espécies.
3. Diferença entre atribuição e cópia de listas.
4. Impressão de números e cálculo de `1000!` com `while`.
5. Identificação de números pares e cálculo de somas acumuladas.
6. Uso de `range()` e compreensões de listas.
7. Contagem com valores de início e fim.
8. Cálculo do comprimento e da posição de sequências de DNA.
9. Embaralhamento de uma sequência pelo algoritmo Fisher-Yates.
10. Cálculo da identidade entre duas sequências alinhadas.
11. Digestão de uma sequência de DNA pela enzima de restrição EcoRI.

## Como executar

1. Abra o arquivo no Jupyter Notebook do VS Code.
2. Selecione um kernel Python.
3. Execute a célula de código com `Shift + Enter`.
4. Consulte a saída abaixo da célula para ver os resultados.

O exercício de contagem usa `3` e `10` como valores padrão. Ao executar o script externamente, também é possível informar outros valores pela linha de comando:

```bash
python Python4.py 3 10
```

## Resultados de verificação

A execução produz as somas esperadas:

```text
Soma dos números pares: 150
Soma dos números ímpares: 286
```

Na análise de EcoRI, foram encontrados dois sítios `GAATTC`, gerando três fragmentos com comprimentos `834`, `432` e `396` pares de bases, ordenados do maior para o menor.
